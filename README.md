# E-Commerce Django REST API

A Django REST Framework (DRF) based e-commerce backend with support for **Products, Categories, Orders, Cart**, and **Stripe Payment Integration**. Includes caching, filtering, and custom middleware for request logging.

## Features

- Category and Product management  
- User Orders and Order Items  
- Shopping Cart with Cart Items  
- Stripe Payment Intent creation and Webhook handling  
- Search, Filtering, and Ordering on Products and Orders  
- Caching of Category and Product lists  
- Custom request logging middleware  
- Pagination for large datasets  

---

## Tech Stack

- Python 3.x  
- Django 4.x  
- Django REST Framework  
- Django Filter  
- Stripe API  
- SQLite/PostgreSQL (any Django-supported DB)
